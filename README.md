A simple digital time clock project created using HTML, CSS and JavaScript.

## Features

- Displays current time
- Displays current date
- Updates every second
- Simple and clean design
- SQL database structure included

## Technologies Used

- HTML
- CSS
- JavaScript
- SQL

## Project Files

- `index.html` - Website structure and clock functionality
- `style.css` - Website design
- `database.sql` - Database table and sample data
- `README.md` - Project information

## How It Works

JavaScript gets the current time from the computer and updates the clock every second.

SQL is included for storing clock records in a database.
